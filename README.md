## Fake Social Media Account Detection

This project develops a **Random Forest machine learning model** to detect fake social media accounts using profile, behavioural, and username-related features.

### Tools

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

### Dataset

The study uses a publicly available dataset containing **3,000 labelled social media accounts**.

### Method

The workflow includes data preprocessing, exploratory data analysis, feature engineering, model training, GridSearchCV optimisation, and performance evaluation.

### Result

The optimised Random Forest model achieves **92.50% accuracy** and **0.9845 ROC-AUC** on the test dataset.
